01 — סקירה
מה זה DevTeam Hub?
פלטפורמת ניהול פיתוח משולבת המאחדת את כל הכלים הנחוצים לצוות פיתוח מקצועי

DevTeam Hub היא מערכת ניהול פיתוח תוך-ארגונית מלאה, המספקת לצוות הפיתוח לוח בקרה אחד לניהול מחזור החיים המלא של מוצר תוכנה — מהרעיון ועד הפריסה לסביבת הייצור.

המערכת פועלת על שרתים פנימיים בלבד, ומתממשקת עם כלים On-Premises כגון Gitea, Jenkins ו-Jitsi — ללא שליחת נתונים רגישים לענן.

בנוסף, המערכת כוללת פורטל לקוחות נפרד המאפשר ללקוחות לצפות בסטטוס הפרויקט, לפתוח כרטיסים, לתקשר עם הצוות ולעיין במסמכים רלוונטיים.

🎫

⚙️
CI/CD Monitoring
מעקב builds בזמן אמת, תוצאות בדיקות, לוגים, התראות על כשלים
🚀
ניהול פריסות
מעקב פריסה לפי סביבה, גרסה, סוג (web/docker/installer), סטטוס

03 — כלים
כלים ותשתית On-Premises
כל הכלים פועלים על שרתים פנימיים ברשת הארגון — ללא תלות בשירותי ענן
🦊
Gitea — שרת Git
חלופה תוך-ארגונית מלאה ל-GitHub.

שימוש:
ניהול repositories, branches, pull requests, code review — כולם מסונכרנים אוטומטית ל-DevTeam Hub דרך Webhooks.

אינטגרציה:
gitea_repo_id repo_url gitea_url שמורים על כל פרויקט ו-PR.
🔧
Jenkins — CI/CD Server
שרת אוטומציה תוך-ארגוני לבניה, בדיקות ופריסה.

שימוש:
כל build מדווח ל-DevTeam Hub דרך Webhook — כולל מספר build, סטטוס, URL ללוג, ותוצאות בדיקות.

נתונים מועברים:
build_number log_url test_results
📹
Jitsi — וידאו-ועידה
שרת וידאו-ועידה בקוד פתוח, מנוהל פנימית.

שימוש:
פגישות צוות, Stand-ups, Code Reviews ו-Retrospectives — עם קישורי Join אוטומטיים מתוך DevTeam Hub.

יתרון:
הקלטות ותמלילי פגישות נשארים על שרתים פנימיים. ייצוא iCal לכל לוח שנה.
🗄️
PostgreSQL / SQLite
מסד נתונים On-Premises מלא.

Dev: SQLite3 (אפס תלויות)
Production: PostgreSQL

כל הנתונים — כרטיסים, מסמכים, CI runs, deployments, messages — מאוחסנים על שרת ארגוני פנימי. גיבויים, replication ו-retention policies בשליטה מלאה של הארגון.
🔍
SonarQube — סקירת קוד
ניתוח סטטי אוטומטי עם Quality Gates.

שימוש:
בדיקת באגים, code smells, כיסוי קוד ו-OWASP SAST — לכל push ב-Jenkins Pipeline.

שפות: Ruby, C#, VB.NET, TypeScript, JS, SQL, HTML
🤖
Ollama — AI Code Review
סקירת קוד מבוססת AI — 100% מקומית.

מודל: Qwen2.5-Coder 32B
שימוש:
מבצע סקירת diff על כל PR — בודק לוגיקה, ארכיטקטורה, שמות ודפוסים. התגובה נכתבת ישירות ב-Gitea.
📋
Grafana Loki — לוגים
איסוף לוגים מרכזי מכל הפרויקטים.

שימוש:
פורמט JSON אחיד, correlation IDs, סינון לפי רמות (labels), 30 ימי retention. קל: 256 MB RAM.
📊
Grafana — Dashboards
דשבורדים והתראות ללוגים.

שימוש:
סינון errors ו-warnings בזמן אמת, נפח לוגים לפי service, LogQL queries, התראות Slack.
🔒 יתרון ה-On-Premises:

כל הנתונים הארגוניים — קוד, כרטיסים, CI logs, deployment history, תקשורת פנימית — נשארים בתוך הרשת הארגונית. אין תלות ב-SLA של ספק ענן חיצוני, אין עלויות per-seat, ואין חשיפת קניין רוחני לצדדים שלישיים.

08 — אבטחה
אבטחת המערכת
8 שכבות אבטחה המגנות על הנתונים, הגישה והתקשורת בכל רמות המערכת
🔑
אימות (Authentication) — Devise
שני מודלי Devise נפרדים: User (צוות פנימי) + CustomerUser (פורטל לקוחות). סיסמאות מוצפנות bcrypt. Password reset מאובטח.
95%
🛡️
הרשאות (Authorization) — Pundit
Pundit policies על כל resource. NotAuthorizedError מיירט כל ניסיון גישה לא מורשה ומפנה עם הודעת שגיאה.
88%
🔒
CSRF Protection — Rails Built-in
כל form ו-AJAX request מאומת עם CSRF token. Turbo ו-Stimulus שולחים X-CSRF-Token אוטומטית.
100%
🪝
Webhook Validation — HMAC Header
כל Webhook מ-Gitea ו-Jenkins מאומת עם secret header. בקשות ללא חתימה תקינה נדחות (403).
90%
🏰
בידוד פורטל הלקוח
CustomerPortal::BaseController יורש מ-ActionController::Base (לא מ-ApplicationController) — אין נגישות למשתנים פנימיים, layouts נפרדים.
95%
🧹
ניקוי קלט — Strong Parameters
כל controller מגדיר permit מפורש לפרמטרים. HTML בהודעות צ'אט עובר ERB::Util.html_escape לפני rendering.
85%
🕐
ניהול Session — Devise
remember_me token מוצפן, timeout session, מחיקת session מאובטחת בהתנתקות. Rails Encrypted Cookies.
90%
🌐
Modern Browser Enforcement
allow_browser versions: :modern דוחה דפדפנים ישנים פגיעים. CSP meta tags מגנים מפני XSS.
80%
